# Security

xDesigner runs on your own machine and doesn't connect to any server. It does run code: it builds and runs your
projects with the .NET SDK, and its renderer loads your project's assemblies (including custom controls) to draw them.
Only open projects you trust, as you would in any IDE.

If you find a security problem in xDesigner itself, please report it privately through GitHub's
[security advisories](https://github.com/CGrebill/xDesigner/security/advisories/new) rather than in a public issue.
Only the latest release receives fixes.
